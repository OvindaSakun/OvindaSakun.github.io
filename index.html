05AUDIO AI / LOCAL WEB APP

Local Soundboard + XTTS

A local soundboard and voice synthesis app for organizing clips, creating reference-based voice profiles and generating WAV audio from text.

  • FastAPI
  • XTTS-v2
  • Coqui TTS
  • PyTorch CPU
Inside the project +

The app preprocesses uploaded audio, saves voice profiles with reference WAV files, and uses XTTS-v2 zero-shot synthesis. Processing trims silence, normalizes audio and exports 24 kHz mono WAV references.

The neural model loads on the first generation request and remains cached. Generation runs through FastAPI’s threadpool while the interface stays responsive. Clips, profiles and generated audio stay local; synthesis uses CPU inference.

Practical constraints

Generation can take 60–90 seconds or longer on low-spec dual-core laptops. Initial setup requires downloading the model.

06VOICE CONVERSION / DESKTOP

Modular RVC TTS

A desktop framework for script-to-speech and audio-to-audio voice conversion, with swappable voice models and adjustable synthesis controls.

  • Python
  • RVC
  • PyTorch
  • CustomTkinter
Inside the project +

The modular pipeline generates anchor speech with Microsoft Edge TTS or accepts existing audio. A local HuBERT model extracts features, an optional FAISS index retrieves voice characteristics, and a VITS-based generator produces the converted audio.

The CustomTkinter interface supports hot-swapping .pth models and .index files, pitch shift, index rate and F0 extraction settings. Output can be played in the interface or exported as WAV.

Implementation

CPU-based inference for compatibility, with output sample rates derived from the selected model. Voice conversion runs locally; text-to-speech anchor generation uses the online Edge TTS service.
